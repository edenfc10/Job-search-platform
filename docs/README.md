# Documentation

This directory holds documentation that explains the system without being part
of its runtime code or deployment configuration.

- `architecture.md` — system design notes.
- `database.md` — database migration notes.
- `local-development.md` — local setup and verification notes.
- `qa-checkpoints.md` — manual QA history and verified checkpoints.
- `security-roadmap.md` — production security work still required.

The root `README.md` remains the primary entry point for the repository.
